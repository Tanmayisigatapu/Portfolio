# Sigatapu NV Tanmayi — Professional Portfolio

A professional, modern, and editorial personal portfolio website built from scratch for **Sigatapu NV Tanmayi**, Computer Science and Engineering student at Lovely Professional University specializing in Data Science, Cloud & DevOps (Agile), AI, and Software Development.

## Design Philosophy

- **Editorial-Tech Aesthetic**: Clean typographic hierarchy, generous whitespace, and purposeful micro-interactions.
- **Calm, Curated Palette**:
  - Deep Navy: `#071A24`
  - Dark Blue: `#0B2430`
  - Warm Ivory: `#F5F3EE`
  - Off-White: `#EEEAE2`
  - Muted Gold: `#B89B5E` (subtle accent)
  - Muted Teal: `#6F8F96`
  - Dark Charcoal: `#17232B`
- **Typography**: Google Fonts `Playfair Display` (editorial serif headings) and `Inter` (sans-serif body).
- **Zero Gimmicks**: No cartoons, no neon glows, no excessive 3D, and no generic templates.

## Structure & Features

- **Sticky Navbar**: With smooth scroll spy, resume download, and responsive mobile drawer.
- **Hero Section**: Balanced presentation between typography and Tanmayi's authentic studio portrait with metadata badges.
- **About Me**: Narrative bio and structured highlight cards (Education, Focus, Minor, Interests).
- **Technical Skills**: Categorized into Programming, Web Development, Databases, Data & Analytics, Tools, and Soft Skills.
- **Selected Projects**:
  1. *Dev Strome 2026* (Featured): 36-hour hackathon coordination platform managing 1,000+ participants.
  2. *Glow AI*: Beauty-tech AI assistant with MediaPipe facial landmark mesh and shade recommendation.
  3. *Power BI Dashboard*: Heart disease risk analytics with demographic slicers and KPI metrics.
  4. *Python Data Science Project*: Exploratory data analysis, correlation matrices, and IQR outlier detection.
- **Professional Experience**: 5-month Non-Technical Internship at Decabyte (US client operations).
- **Achievements**: Milestone cards highlighting 1000+ attendees managed, 2nd place coordinator award, Google Student Ambassador recognition, and Python training.
- **Certificates & Interactive Modal**: 8 high-resolution credentials with zoom in/out, keyboard navigation, and full-view display without text clipping.
- **Learning & Education Timelines**: Chronological milestones and academic background at LPU, Sarada, and STBEM.
- **Contact & Footer**: Direct email copy with toast notification, phone, LinkedIn, and GitHub links.

## How to Run Locally

You can serve this portfolio using any local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

Open `http://localhost:3000` in your web browser.
